Under the Hood

Rift Architecture

One native player. Every source plugged in behind a single seam — the UI never learns where audio comes from.

Control flow — play / pause / seek / next
Data & audio — metadata, library, playback state
Network — InnerTube API & OAuth

The seam: nothing above PlaybackSource knows whether audio comes from a WebView, a local file, or a future native extractor. Swap the conformer, keep the UI.
